# Прописи Бори

Android-приложение для домашнего английского: папа фотографирует страницу словаря, Claude Opus
вытаскивает пары «английское слово — перевод», а дальше пять вкладок: **Гармошка** (письмо на время,
секунды на букву, рекорды с конфетти), **Слова** (карточки, самопроверка, контрольная с микрофоном,
рассказ на словах урока), **Грамматика**, **Домашка** и **Текст** (в работе).

## Что умеет

### Гармошка

- **Фото страницы → список слов.** Камера или галерея, до четырёх фото за раз. Разбор делает
  `claude-opus-5` через Messages API (инструмент `save_vocabulary`, strict JSON). Слова берутся как
  напечатаны, вместе с артиклем и «to» (a hen, to plant): Боря пишет их целиком, буквы считаются целиком.
- **Ручной ввод списка**: строки вида `hen - курица`.
- **Тренировка**: большое слово на экране, кнопка СТАРТ/СТОП, экран не гаснет. После остановки:
  время, секунд на букву, вердикт (рекорд / быстрее среднего / записано), кнопка «Дальше» ведёт к
  следующему ненаписанному слову списка.
- **Прогресс**: сколько букв написано за всё время, по каждому языку рекорд, среднее, последние 5 слов,
  график (точки — слова, линия — тренд за 5 слов, пунктир — средняя, звезда — рекорд, подсветка —
  сегодняшние слова) и таблица «сколько уходит на слово из 4 / 5 / 6 / 7 букв». Единица одна: секунд на букву.
- **Геймификация**: конфетти и вибрация на новый рекорд и на рубежи 100, 250, 500, 1000… букв;
  серия слов подряд быстрее среднего. Рекордом считаются слова от 3 букв.
- **Повторы внутри урока**: таблица «слово | 1-й | 2-й | 3-й | Δ» на экране списка плюс фраза «второй
  раз то же слово Боря обычно пишет на N% быстрее». Слова сравниваются по тексту без артикля, так что
  «hen» из приложения и «a hen» с бумаги — одно слово, и бумажные результаты попадают в таблицу урока.
  На экране прогресса остаётся только итоговая фраза.
- **Бумажная статистика** сентября 2026 уже загружена: 11 слов третьего урока по-английски в два
  прохода (a hen, a goose, a seed, a walk, work, wheat, to plant, to do, to grow, to cut, warm) и те же
  11 слов по-русски в один проход (курица, гусь, семя, прогулка, работа, пшеница, сажать, делать,
  растить, резать, теплый). Новые бумажные результаты добавляются кнопкой
  «Добавить результат с бумаги».
- **Обновление из приложения**: при запуске (не чаще раза в 6 часов) проверяется последний релиз на
  GitHub; если сборка новее, на главном экране появляется баннер «Обновить», APK скачивается и
  открывается системный установщик. Ручная проверка в настройках.
- **Резервная копия**: экспорт и импорт JSON в настройках.

### Слова
- **Обучалка**: карточка «слово + перевод», смахивание влево/вправо, озвучка английского голосом Android.
- **Училка**: русское слово, по нажатию открывается английское; «знал» / «ещё повторю», невыученные
  возвращаются в конец круга; итог «сразу знал N из M».
- **Контроша**: русское слово, микрофон включается сам, ответ по-английски распознаёт Google. Совпадение
  проверяется терпимо (артикль, порядок слов, похожие по звучанию слова), для фраз запасной судья —
  модель. Одна ошибка — всё с первого слова. Прохождение сохраняется: с какой попытки и за сколько.
- **Рассказ**: Opus сочиняет смешную историю на 70–110 слов со всеми словами урока; слова подсвечены,
  есть перевод по переключателю и чтение вслух.

## Как получить APK

Каждый пуш в `main` или в ветку `claude/**` собирает подписанный APK через GitHub Actions и публикует его
в разделе **Releases** репозитория (тег `build-N`, `versionCode` = N). Уже установленное приложение само
предложит обновиться. Для первой установки на телефоне:

1. Открой https://github.com/atsakunov-prog/PravkaBoard/releases
2. Скачай `pravka-<версия>-buildN.apk` из последнего релиза.
3. Открой файл, разреши установку из этого источника (Android спросит один раз).

Если Actions ещё не включены (репозиторий — форк), один раз зайди во вкладку **Actions** на GitHub и
нажми «I understand my workflows, go ahead and enable them», затем перезапусти workflow.

Все сборки подписаны одним ключом из `keystore/pravka.jks`, поэтому новая версия ставится поверх старой
без удаления и без потери статистики. Локальная сборка (`./gradlew assembleRelease` без CI) получает
`versionCode` 1 и номер сборки 0: она подходит для отладки, но поверх облачной сборки не встанет. Ключ лежит в репозитории намеренно: приложение личное и
распространяется только через APK, в Google Play не идёт.

## Первый запуск

1. Настройки (шестерёнка) → вставить API-ключ Anthropic → Сохранить. Ключ хранится только на телефоне.
2. Слова → «Сфотографировать страницу» → «Распознать слова (Opus)».
3. Открыть список, нажать «Начать писать».

## Сборка локально

Нужны JDK 17+ и Android SDK (platform 36, build-tools 35 или новее). В `local.properties` указать
`sdk.dir=/путь/к/sdk`, затем:

```
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`.

## Структура

```
app/src/main/java/ru/tsakunov/pravka/
  PravkaApp.kt              Application, ручной DI
  MainActivity.kt
  data/                     Room: WordList, WordItem, Attempt; Repository; Settings; посев бумажных данных
  domain/Stats.kt           подсчёт букв, статистика по языку, вердикт попытки, серии, рубежи
  domain/Repeats.kt         группировка попыток по слову: первый / второй / третий проход
  domain/ByLength.kt        сколько уходит на слово из N букв
  api/ClaudeApi.kt          общий вызов Messages API с принудительным инструментом (strict JSON)
  api/ClaudeVocabParser.kt  фото словаря → список пар
  api/ClaudeStory.kt        рассказ на словах урока
  api/ClaudeJudge.kt        судья для контроши по фразам
  api/Updater.kt            GitHub Releases → скачивание APK → системный установщик
  domain/Matching.kt        сопоставление распознанной речи с ожидаемым ответом
  ui/PravkaRoot.kt          навигация
  ui/screens/               Home (Гармошка), List, Practice, Progress, Words, Learn, Teach, Test, Story, Settings
  ui/components/            SpeedChart (Canvas), RepeatTable, ConfettiOverlay, Speech (TTS и распознавание), диалоги
```

Стек: Kotlin 2.3, Jetpack Compose (BOM 2026.01.01, Material 3), Room 2.8 + KSP, Navigation Compose,
OkHttp. Минимальный Android 8.0 (API 26).
