# Прописи Бори

Android-приложение для домашнего английского: папа фотографирует страницу словаря, Claude Opus
вытаскивает пары «английское слово — перевод», а дальше шесть вкладок: **Гармошка** (письмо на время,
секунды на букву, рекорды с конфетти), **Слова** (карточки, самопроверка, контрольная с микрофоном,
рассказ на словах урока), **Грамматика** (страница правила превращается в уровни-тренажёры),
**Домашка** (Opus проверяет фото тетради и подсвечивает ошибки), **Текст** (чтение вслух с микрофоном и
переводом, слова в минуту) и **Статистика** (всё вместе за неделю, месяц или всё время). Иконка сканера в
шапке любой вкладки принимает всю домашку одним пакетом фото и раскладывает её по вкладкам.

Для Claude Code в репозитории есть `CLAUDE.md`: сборка, релизы, карта кода и правила, которые легко нарушить.

## Что умеет

### Гармошка

- **Фото страницы → список слов.** Камера или галерея, до восьми фото за раз. Разбор делает
  `claude-opus-5` через Messages API (инструмент `save_vocabulary`, strict JSON). Слова берутся как
  напечатаны, вместе с артиклем и «to» (a hen, to plant): Боря пишет их целиком, буквы считаются целиком.
- **Ручной ввод списка**: строки вида `hen - курица`.
- **Тренировка**: большое слово на экране, кнопка СТАРТ/СТОП, экран не гаснет. После остановки:
  время, секунд на букву, вердикт (рекорд / быстрее среднего / записано), кнопка «Дальше» ведёт к
  следующему ненаписанному слову списка.
- **Прогресс**: сколько букв написано за всё время, по каждому языку рекорд, среднее, последние 5 слов,
  график (точки — слова, линия — тренд за 5 слов, пунктир — средняя, звезда — рекорд, подсветка —
  сегодняшние слова) и таблица «сколько уходит на слово из 4 / 5 / 6 / 7 букв». Единица одна: секунд на букву.
- **Геймификация**: конфетти и вибрация на новый рекорд и на рубежи 100, 250, 500, 1000… букв;
  серия слов подряд быстрее среднего. Рекордом считаются слова от 3 букв.
- **Повторы внутри урока**: таблица «слово | 1-й | 2-й | 3-й | Δ» на экране списка плюс фраза «второй
  раз то же слово Боря обычно пишет на N% быстрее». Слова сравниваются по тексту без артикля, так что
  «hen» из приложения и «a hen» с бумаги — одно слово, и бумажные результаты попадают в таблицу урока.
  На экране прогресса остаётся только итоговая фраза.
- **Бумажная статистика** сентября 2026 уже загружена: 11 слов третьего урока по-английски в два
  прохода (a hen, a goose, a seed, a walk, work, wheat, to plant, to do, to grow, to cut, warm) и те же
  11 слов по-русски в один проход (курица, гусь, семя, прогулка, работа, пшеница, сажать, делать,
  растить, резать, теплый; времена гуся и прогулки на листке были перепутаны и исправлены в посеве
  версии 5). Новые бумажные результаты добавляются кнопкой «Добавить результат с бумаги».
- **Обновление из приложения**: при запуске (не чаще раза в 6 часов) проверяется последний релиз на
  GitHub; если сборка новее, на главном экране появляется баннер «Обновить», APK скачивается и
  открывается системный установщик. Ручная проверка в настройках.
- **Резервная копия**: экспорт и импорт JSON в настройках.

### Слова
- **Обучалка**: карточка «слово + перевод», смахивание влево/вправо, озвучка английского голосом Android.
- **Училка**: русское слово, по нажатию открывается английское; «знал» / «ещё повторю», невыученные
  возвращаются в конец круга; итог «сразу знал N из M».
- **Контроша**: русское слово, микрофон включается сам, ответ по-английски распознаёт Google. Совпадение
  проверяется терпимо (артикль, порядок слов, похожие по звучанию слова), для фраз запасной судья —
  модель. Одна ошибка — всё с первого слова. Прохождение сохраняется: с какой попытки и за сколько.
- **Рассказ**: Opus сочиняет смешную историю на 70–110 слов со всеми словами урока; слова подсвечены,
  есть перевод по переключателю и чтение вслух.

### Грамматика
- Фото страницы с правилом. Opus разбивает его на уровни (для множественного числа: просто -s, -es,
  согласная + y → -ies, слова на -o, -f → -ves, особые слова), к каждому уровню 8–12 карточек «слово → форма».
- Тренажёр: слово на экране, Боря говорит форму вслух, папа открывает ответ и жмёт «верно» или «не верно».
  Пять верных подряд проходят уровень и открывают следующий, конфетти. Прогресс по уровню хранится.

### Домашка
- Фото сделанного упражнения. Opus читает задание и ответы, ставит по каждому пункту «верно», «не верно»
  или «не сделано». Первая проверка показывает только красное, без подсказок: сначала Боря исправляет сам.
- Второе фото после исправлений: у оставшихся ошибок появляется подсказка с правилом. С третьей попытки
  открывается и правильный ответ. Счёт «12 из 13», конфетти за всё верно, значок «без ошибок с первого раза».

### Текст
- Фото страниц книжки (до 20 снимков). Opus переписывает текст (реплики в облачках включительно) и переводит.
- Чтение с микрофоном: текст разбит на предложения, Боря читает предложение по-английски, делает паузу,
  говорит перевод по-русски, приложение само переходит к следующему. Микрофон слушает английский и русский
  шаги по отдельности (Google распознаёт один язык за раз), поэтому пауза между чтением и переводом важна.
- В конце Opus разбирает каждое предложение: чтение (чисто / с заминкой / не получилось) и перевод
  (верно / наполовину / не то) с короткой подсказкой ребёнку. Ошибки распознавания речи модель списывает,
  считаются только настоящие пропуски и замены слов. Без ключа или сети чтение оценивается локально по
  совпадению слов, перевод остаётся непроверенным.
- Статистика: слова в минуту по чистому времени чтения (без пауз на перевод), сравнение с лучшим и с
  прошлым микрофонным чтением этого текста («быстрее на 12%, перевод точнее на 2»). Конфетти за рекорд
  скорости или за более точный перевод.
- Запасной режим «Секундомер»: СТАРТ, папа жмёт «запинка», СТОП. Чтение короче трёх секунд не записывается.
- Рассказы Opus из уроков тоже открываются здесь; ненужный можно удалить корзинкой.

### Статистика
- Переключатель периода: неделя, месяц, всё время. Всё считается по событиям с временем, поэтому
  цифры за неделю и за месяц честные, а не «с начала времён».
- Время занятий: сколько всего, сколько дней с занятиями, серия дней подряд, столбики минут по дням,
  сложенные по видам (Гармошка, Слова, Грамматика, Текст), и раскладка времени по видам.
- По разделам: Гармошка (букв, слов, секунд на букву по языкам, лучшие слова), Слова (сколько слов сказал
  верно на контроше, сколько контрош, с какой попытки; училка и обучалка), Грамматика (ответов, точность,
  уровней пройдено, лучшая серия), Домашка (домашек, ошибок с первого раза и их доля, без ошибок сразу,
  исправлено до конца), Текст (чтений, лучшая и средняя скорость, чисто прочитанных предложений и верных
  переводов с микрофоном).
- Под каждым блоком сравнение с предыдущим таким же периодом: «на 12% больше букв, чем неделей раньше»,
  «ошибок меньше на 5 п.п.». Заголовок блока ведёт на вкладку, Гармошка — на подробный прогресс с графиком.
- Обучалка, училка и тренажёр грамматики пишут в журнал занятий (карточек, слов, ответов, время), остальные
  разделы считаются по своим таблицам.

### Вся домашка одним пакетом
- Иконка сканера в шапке любой вкладки. Фотографируешь всю домашку подряд (до 24 фото, любой порядок):
  словарь, правило, упражнения с ответами, страницы книжки. Opus сначала смотрит, что на каждой странице,
  потом каждый вид уходит своему разборщику: словарь становится уроком Гармошки и Слов, правило — темой в
  Грамматике, упражнения — проверкой в Домашке, страницы книжки — текстом. Из карточки разбора всё
  открывается в один тап.
- Переключатель «Пакетная обработка» отправляет разбор через Message Batches API: вдвое дешевле, ответ
  обычно через 5–30 минут (по договору до суток). Сортировка страниц всё равно идёт сразу, чтобы понять,
  что отправлять. Пакет проверяется при каждом запуске приложения и раз в полминуты, пока открыт экран
  «Вся домашка»; кнопка обновления в шапке проверяет вручную. Приложение можно закрывать.
- Разбор, прерванный закрытием приложения в обычном режиме, через десять минут помечается ошибкой,
  части, которые успели пройти, остаются.

## Как получить APK

Каждый пуш в `main` или в ветку `claude/**` собирает подписанный APK через GitHub Actions и публикует его
в разделе **Releases** репозитория (тег `build-N`, `versionCode` = N). Уже установленное приложение само
предложит обновиться. Для первой установки на телефоне:

1. Открой https://github.com/atsakunov-prog/PravkaBoard/releases
2. Скачай `pravka-<версия>-buildN.apk` из последнего релиза.
3. Открой файл, разреши установку из этого источника (Android спросит один раз).

Если Actions ещё не включены (репозиторий — форк), один раз зайди во вкладку **Actions** на GitHub и
нажми «I understand my workflows, go ahead and enable them», затем перезапусти workflow.

Все сборки подписаны одним ключом из `keystore/pravka.jks`, поэтому новая версия ставится поверх старой
без удаления и без потери статистики. Локальная сборка (`./gradlew assembleRelease` без CI) получает
`versionCode` 1 и номер сборки 0: она подходит для отладки, но поверх облачной сборки не встанет. Ключ лежит в репозитории намеренно: приложение личное и
распространяется только через APK, в Google Play не идёт.

## Первый запуск

1. Настройки (шестерёнка) → вставить API-ключ Anthropic → Сохранить. Ключ хранится только на телефоне.
2. Слова → «Сфотографировать страницу» → «Распознать слова (Opus)».
3. Открыть список, нажать «Начать писать».

## Сборка локально

Нужны JDK 17+ и Android SDK (platform 36, build-tools 35 или новее). В `local.properties` указать
`sdk.dir=/путь/к/sdk`, затем:

```
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`.

```
  api/ClaudeStory.kt        рассказ на словах урока

  api/ClaudeHomework.kt     проверка домашки по фото
  api/ClaudeGrammar.kt      страница правила → уровни тренажёра
  api/ClaudeReading.kt      страницы книжки → текст для чтения
  api/ClaudeReadingJudge.kt разбор чтения с микрофоном по предложениям
  api/ClaudeSorter.kt       фото всей домашки → что на какой странице
  api/ClaudeBatch.kt        Message Batches: создать пакет, опросить, забрать итоги
  api/Updater.kt            GitHub Releases → скачивание APK → системный установщик
  domain/Matching.kt        сопоставление распознанной речи с ожидаемым ответом
  domain/Homework.kt, Grammar.kt  модели результатов проверки и тренажёра (JSON в Room)

  domain/Intake.kt          части разбора всей домашки
  domain/Overview.kt        общая статистика: периоды, время по дням и видам, срезы по разделам
  ui/vm/IntakeCoordinator.kt  сортировка страниц, параллельные или пакетные запросы, раскладка по вкладкам
  ui/PravkaRoot.kt          навигация
  ui/screens/               Home (Гармошка), List, Practice, Progress, Words, Learn, Teach, Test, Story,

                            с микрофоном и секундомером), IntakeScreen (вся домашка), StatsScreen, Settings

```

Стек: Kotlin 2.3, Jetpack Compose (BOM 2026.01.01, Material 3), Room 2.8 + KSP, Navigation Compose,
